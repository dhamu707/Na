# LinkChat - Private 1-on-1 Ephemeral Messenger

LinkChat એ વ્હોટ્સએપ (WhatsApp) જેવી UI ધરાવતી, એન્ડ-ટુ-એન્ડ ૧-ઓન-૧ પ્રાઇવેટ ચેટ વેબ એપ્લિકેશન છે. આમાં કોઈ સાઇન-અપ કે લોગિનની જરૂર નથી. યુઝર એક જ ક્લિકમાં પોતાનો સીક્રેટ રૂમ બનાવીને સાથીદાર સાથે લિંક શેર કરી શકે છે.

---

## 🌟 ફીચર્સ (Features)

* **એનોનિમાઇસ ઓથેન્ટિકેશન (Anonymous Auth):** યુઝરે નામ, ઈમેલ કે ફોન નંબર આપવાની જરૂર નથી.
* **૨-યુઝર લિમિટ વાળા પ્રાઇવેટ રૂમ (Max 2 Users Limit):** એક રૂમમાં માત્ર ૨ સભ્યો જ જોડાઈ શકે છે. ત્રીજો યુઝર આવે તો "Room Full" દેખાડે છે.
* **રીઅલ-ટાઇમ ચેટ (Realtime Chatting):** ત્વરિત ટેક્સ્ટ મેસેજ મોકલો અને મેળવો.
* **વોઇસ મેસેજ (Voice Recording):** ઇન-બિલ્ટ રેકોર્ડર વડે ઓડિયો નોટ્સ મોકલો.
* **ઇમેજ શેરિંગ (Image Sharing):** ફોટો શેર કરો અને ક્લિક કરીને મોટી ઇમેજ પ્રિવ્યૂ કરો.
* **ઇમોજી પિકર (Emoji Support):** મેસેજ સાથે સરળતાથી ઇમોજી ઉમેરો.
* **ટાઇપિંગ ઇન્ડિકેટર અને સીન રેસિપ્ટ્સ (Typing & Read Receipts):** સાથી ટાઇપ કરી રહ્યો છે કે નહીં અને મેસેજ વંચાઈ ગયો છે (Double Blue Tick) તેની જાણકારી.
* **ઓનલાઇન/ઓફલાઇન અને લાસ્ટ સીન (Online/Offline Status):** સાથી યુઝરનું લાઈવ સ્ટેટસ.
* **મેસેજ ડિલીટ અને કોપી (Delete & Copy):** મેસેજ પર લોંગ પ્રેસ કરીને કોપી કે પોતાના મેસેજ ડિલીટ કરી શકાય છે.
* **ડાર્ક / લાઈટ મોડ (Dark & Light Theme):** વ્હોટ્સએપ શૈલીમાં મોડ સ્વિચર.
* **PWA & Installable App:** મોબાઈલ અને ડેસ્કટોપમાં એપની જેમ ઇન્સ્ટોલ કરી શકાય છે.
